# Security Policy

## Supported versions

Security fixes are developed against the active stabilization branch. The v2.1.0 source currently on `main` is incomplete and should not be treated as a supported client-ready release.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to **trintechdigitaldefense@gmail.com**. Do not publish exploit details or sensitive client information in public issues.

Include:
- affected version, branch, and commit;
- a concise description and potential impact;
- safe reproduction steps using a local test fixture where possible;
- any suggested mitigation.

TrinTech Digital Defense aims to acknowledge reports within 72 hours. This is a response target, not a guarantee of resolution time.

## Safe-use requirements

ApexRecon is intended only for systems owned by the operator or covered by explicit written authorization. Do not use it to scan third-party assets without permission. Do not include client credentials, private keys, or confidential evidence in public issues or pull requests.
